# 共用
这类题不用写 surfaces、bodies，写 `"scene":{"surfaces":[],"bodies":[],"<实验室名>":{…}}`。引擎按你给的物理条件自己算，你不要把结论写进场景。一个 scene 只能选一个实验室、circuit 或 script；它们不会与原生 bodies/forces/em 自动耦合，跨模型联立请用一个 ode 自写方程。
取量：`val(名字)`，名字见各板块。例如 `"expr":"val(p_A)"`。时刻：`{"event":"end"}` 结束、`{"event":"start"}` 开始、`{"event":"time","t":2}` 某一时刻、`{"event":"mark","name":"节点名"}` 引擎标的节点。
“某量到达某值的时刻”写 `{"event":"when","expr":"val(x_甲)","dir":1,"n":1}`，expr 穿过 0 的时刻。
表达式里可写 params 的名字。字母题同样给数值并写 samples。能用 val 就不要写只含参数的式子，否则标为“仅代数”。
选择题每个选项一项 ask；每个可计算选项必须提供 `option.claim` 布尔判断式，用与 expr 相同的 at/times/vals。例 `"option":{"label":"A","text":"电流为负","correct":true,"claim":"val(Is)<0"}`；相等用 `approx(val(I),I0,1e-6,0)`，不直接用 == 比较浮点。跨时刻可用 `"times":{"t1":{"event":"time","t":1}}` 后写 `val(Is,t1)<0`。仅概念选项允许只写 correct，来源为 AI，未经核验；改条件后 correct 可省略，结论以重新算出的 claim 为准。
内置物理与 ode/script/自定义派生量分开分级：后者只证明积分/代入正确，不能声称已核验物理。vals 原始读数的别名保留来源，另写公式的派生量属于自定义计算；未写 check 的步骤也未核验。不要自行输出 verified、source、claimValue。

“某量达到某值”“第几次”都能用。解题过程按上面的要求写成一步一步，每步的 `at` 写对应节点，让画面停在那一刻；再写 `idea` 和 `notes`。

# 电磁感应
`"induction":{"kind":"rails|frame|rotate|coil", …}`，电动势和安培力由引擎算，不要手写。
- 大小量保持原写法 `val(I)`、`val(emf)`；新增带符号量 `val(Is)`、`val(emfs)`。方向题必须用带符号量，不能用 I、emf 或 abs(Is) 代替方向判断；先在 solution 说明参考方向，正负号和单位一并给出。B>0 朝 +z（纸面外）。
- rails 的 x 沿导轨正方向；局部坐标上轨 y=+L/2、下轨 y=−L/2。棒的 Is 以上轨→下轨（−y）为正，emfs=BLv 沿此方向为正（v×B）；第一根棒读 Is/emfs，多棒读 `Is_棒id`、`emfs_棒id`。支路 `Is_b1` 等以下轨→上轨为正。因此单棒向 +x 运动、B>0 时 Is>0，闭合回路从 +z 看顺时针。倾斜导轨仍使用这套局部右手坐标和 B 的法向分量。
- frame、coil：从 +z 看逆时针为正，磁通量法向 +z，emfs=−dΦ/dt，Is=emfs/R。+z 磁通量增加时 Is<0、减少时 Is>0。对比线框也有 `Is_乙`、`emfs_乙`（主框读无后缀的量）。
- rotate：omega>0 表示从 +z 看逆时针；电动势/电流以内端→外端为正，emfs=B*omega*(L²−r0²)/2。不是绕外接支路的方向。
- 电流过零时刻可写 `{"event":"when","expr":"val(Is)","dir":1}`（负转正），正转负则 dir:-1；需比较两侧非零电流才能确认反转，零电流区间不等于反转。恰好无电流时不声明顺/逆时针。q、Qh 仍为累计电荷量大小和焦耳热。
- 导轨上的棒 rails：`"L":间距,"B":磁感应强度(可含 t、x),"regions":[{"x":[a,b],"B":…}]（分段磁场，和 B 二选一）,"incline":倾角度数,"mu":…,"rods":[{"id":"ab","m":…,"r":棒电阻,"x":初位置,"v":初速度,"F":外力(可含 t、x、v),"drive":强制速度,"fixed":true}],"branches":[{"R":…,"C":…,"E":…,"q0":电容初始电荷量,"on":"t<3","short":"t<2"}],"duration":秒`。branches 是导轨左端的支路，每条 R、C、E 串联，可写多条；on 成立时接通（不写就一直接通），short 成立时电容被短接。棒之间并联。倾斜时 x 沿导轨向下为正。取量 v_ab x_ab a_ab F_ab Q_ab I_ab，I emf U（导轨间电压）Qh（总焦耳热）q（通过第一根棒的电荷量）W（外力做功）Pext（外力功率），支路 I_b1 Q_b1 P_b1 Uc_b1 q_b1。节点 `速度稳定`。
- 线框穿磁场 frame：`"w":宽,"h":高,"R":…,"m":…,"N":匝数,"x":左下角x,"y":左下角y,"v":[vx,vy],"F":[Fx,Fy],"gravity":true,"regions":[{"x":[a,b],"y":[c,d],"B":…}],"duration":秒`。B 可含 t、x、y，向外为正。取量 x y vx vy v I emf F Qh q phi。节点 `开始切割`、`磁通量不再变`。
  - 比较两个线框（甲、乙只差电阻或质量）：主线框写 `"label":"甲"`，再写 `"also":[{"label":"乙","R":"2*R","dy":竖直错开距离}]`，两个一起模拟并排画。取量加后缀 `vx_乙` `Qh_乙` `F_乙` `I_乙` `q_乙`，节点 `乙开始切割`、`乙磁通量不再变`。问比值就写 `val(Qh)/val(Qh_乙)`。
- 转动的棒 rotate：`"L":…(可含转角 a),"r0":内端半径,"B":…,"omega":…,"R":…`。取量 emf I P L F。
- 磁场随时间变的线圈 coil：`"N":…,"S":面积,"B":"0.5*t","R":…`。取量 B emf I Qh q。

# 交变电流
`"ac":{"source":{…},"chain":[…],"duration":秒}`。电源写 `{"U":有效值,"f":频率,"r":内阻}`、`{"Um":峰值,"w":角频率}`，或线圈 `{"N":…,"B":…,"S":…,"w":…,"r":…}`。
chain 从电源到负载依次写：`{"kind":"R","id":"线路","R":…}` 串联电阻，`{"kind":"T","id":"升压","n1":…,"n2":…}` 理想变压器，`{"kind":"load","id":"用户","R":…}` 负载。R、n1、n2 可含 t。
取量：Um E（有效值）T f e（瞬时）；变压器 U1_id I1_id U2_id I2_id P_id；电阻和负载 U_id I_id P_id。

# 电路
`"circuit":{"duration":秒,"transient":true,"nodes":{"n0":[0,0],…},"elements":[{"id":"电源","kind":"battery","a":"正极节点","b":"负极节点","E":12,"r":1},…]}`。
kind：battery、R、rheostat（R 可含 t）、lamp、wire、switch（`"on":"t<2"` 成立时闭合）、ammeter、voltmeter、capacitor（`"C":…,"U0":…`）。
`transient:true` 算电容充放电；不写时电容按稳态断路。灯泡有伏安曲线时加 `"curve":[[U,I],…]`，引擎解工作点。
取量函数 `I(元件)`、`U(元件)`、`P(元件)`、`Vn(节点)`；`val(q_C1)` 电容带电量。I 为大小；`Is(元件)` 或 `val(Is_元件id)` 为有符号电流，统一以该元件声明的 a→b 为正，包含电源（正常供电时内部 b→a，Is<0）。方向题写 Is，不取绝对值。

LC 振荡电路写 `"scene":{"surfaces":[],"bodies":[],"lc":{"L":0.01,"C":1e-6,"R":0,"U0":10,"duration":秒}}`（或 q0、I0 给初始电荷、电流；R 可省，有 R 是阻尼振荡）。取量 q（上极板电荷）、i（回路电流，给上极板充电为正）、I（大小）、uC、uL、EC（电场能）、EL（磁场能）、E、Q（电阻焦耳热）、T（周期 2π√(LC)）、f。节点 `放电完毕`（q=0）、`充电完毕`（i=0），第 n 次加 "n"。

# 带电粒子
`"particle":{"fields":[…],"particles":[…],"walls":[…],"g":…,"duration":秒}`，三维积分，z 垂直纸面向外。
- 场：`{"id":"Ⅰ区","kind":"B","B":数值(向外为正)或[Bx,By,Bz],"region":…}`、`{"kind":"E","E":[Ex,Ey],"region":…}`、`{"kind":"Q","Q":…,"at":[x,y]}`。B、E 可含 t、x、y，方波写 `(mod(t,T)<T/2)-(mod(t,T)>=T/2)`。
- region：`{"x":[a,b],"y":[c,d]}`（只写一个方向就是一条带）、`{"center":[x,y],"radius":r}`、`{"poly":[[x,y],…]}`、`{"side":{"from":[x,y],"to":[x,y]}}`（直线 from→to 的左侧）。
- 粒子：`{"id":"甲","q":…,"m":…,"pos":[x,y,z],"vel":[vx,vy,vz]}`；可写多个。
- 一个区域里的场要盖掉前面的场时加 `"over":true`（如磁屏蔽区）。
- 挡板：`{"id":"板","from":…,"to":…,"reflect":true,"flip":true,"hole":[a,b]}`，不写 reflect 打上就停，flip 是碰后电性反转，hole 是沿挡板的小孔段。
- 相碰：`"collisions":[{"bodies":["甲","乙"],"e":1}]`，不带电的写 q:0。节点 `甲乙相碰`。
取量 x_甲 y_甲 z_甲 v_甲 vx_甲 vy_甲 vz_甲 KE_甲 r_甲 T_甲，xmin_甲 xmax_甲 ymin_甲 ymax_甲（穿过小孔之后的极值）。节点 `甲进入Ⅰ区`、`甲离开Ⅰ区`、`甲打到板`、`甲穿过板`。题目只给字母时取让周期在 1～10 s 的数值。

# 静电场
`"electro":{"k":静电力常量,"charges":[{"id":"Q1","q":…,"at":[x,y]}],"uniform":[Ex,Ey],"probes":[{"id":"O","at":[x,y]}],"scan":{"from":…,"to":…},"mover":{"id":"e","q":…,"m":…,"at":…,"v":[vx,vy]},"range":[x0,y0,x1,y1],"duration":秒}`。
引擎画电场线和等势线。取量 E_O Ex_O Ey_O phi_O；scan 是探针沿直线走，取量 s_scan phi_scan E_scan Ex_scan，φ-x 图写 `plot`；mover 的 x_e y_e v_e KE_e EP_e。

# 万有引力
`"gravity":{"G":…,"bodies":[{"id":"地球","m":…,"pos":[x,y],"vel":[vx,vy],"fixed":true},…],"kicks":[{"on":"卫星","t":…,"factor":1.2},{"on":"卫星","at":"apsis","n":1,"dv":…}],"duration":秒}`。
任意多个天体互相吸引，双星不写 fixed。数值可取 G=1 和方便的单位，物理量之比不变。取量 r_id v_id a_id T_id sma_id（半长轴）E_id Ek_id Ep_id rmin_id rmax_id x_id y_id。节点 `卫星近点`、`卫星远点`、`卫星 点火`。

# 振动与波
`"wave":{"range":[a,b],"duration":秒,"steady":true,"plane":false,"sources":[{"id":"S1","x":…,"y":…,"A":…,"T":周期或"f":频率,"v":波速或"lambda":波长,"phase":初相角度,"t0":起振时刻,"dir":1,"cycles":振动几个周期}],"points":[{"id":"P","x":…,"y":…}],"wall":{"x":…,"fixed":true}}`。
dir 1 向右，-1 向左，不写两边都传。steady:true 表示已传遍全程；不写时能看到波前传播。plane:true 是水面二维干涉。
题目给出 t=0 时刻波形和传播方向的行波（最常见），不写波源 x，写 `{"crest":t=0 时某个波峰的 x,"A":…,"lambda":…或"T":…,"v":…,"dir":1 或 -1}`，引擎按这个波形铺满全程传播。
“质点 P 第 2 次到达平衡位置”写 `"at":{"event":"when","expr":"val(y_P)","n":2},"expr":"t"`；到达波峰用 `val(vy_P)` 过零且 `val(y_P)>0`。
取量 lambda T v f、y_P vy_P amp_P、dr_P（波程差）。振动图写 `plot`。弹簧振子、单摆走力学场景。

# 光学
`"optics":{"n0":1,"media":[…],"mirrors":[{"from":…,"to":…}],"screens":[{"id":"屏","from":…,"to":…}],"rays":[{"id":"a","from":[x,y],"dir":入射方向角度(可含 t)或[dx,dy],"color":"#b5302a"}],"duration":秒}`。
介质：`{"id":"玻璃","n":…,"poly":[[x,y],…]}`、`{"id":"球","n":…,"circle":[x,y,R]}`、半圆砖 `{"id":"砖","n":…,"arc":{"center":[x,y],"radius":R,"from":180,"to":360}}`。真实光线追踪，到界面按折射定律走，超过临界角全反射。
取量：第 k 次到界面 i_a1 r_a1 tir_a1 x_a1 y_a1（k 从 1 起），C_玻璃（临界角）n_玻璃 path_a（总路程）in_a（在介质里的路程）time_a（总时间）hits_a exit_a。
双缝干涉写 `"slit":{"lambda":600e-9,"d":0.2e-3,"L":1,"a":单缝宽(可省),"film":{"slit":1,"n":1.5,"e":6e-6},"probes":[{"id":"P","x":3e-3}],"duration":1}`，单位 m；film 是在第 1（上）或第 2（下）条缝前插入薄片。lambda、d、L、film.e 可含 t，演示条纹怎样变。屏上光强按精确光程差算。取量 dx（条纹间距 Lλ/d）、x0（零级亮纹位置，插片后移向插片一侧）、xb_1 xb_m1（第 ±1 级亮纹）、xd_0（暗纹）、delta_P（P 点光程差）、order_P（光程差除以 λ）、I_P（相对光强）、bright_P/dark_P（1 或 0）。

# 热学
两种写法。活塞都在一根缸里时用链式：
`"gas":{"A":截面积,"patm":大气压,"angle":缸轴与水平夹角（度，90 竖直）,"chambers":[{"id":"A","p":初压强(可省,由平衡算),"L":长度,"T":温度,"Cv":…}],"pistons":[{"id":"活塞","m":…,"len":厚度或液柱长,"stops":[下卡环位置,上卡环位置],"F":外力}],"open":true,"total":封闭缸总长,"steps":[…]}`。
从缸底到缸口依次是：第 1 段气体、第 1 个活塞、第 2 段气体……。液柱当活塞写 m、len。
每一步：`{"label":"加热","duration":3,"T":{"A":"300+100*u"},"adiabatic":["B"],"tilt":0,"patm":…,"force":…,"add":{"A":…},"leak":{"A":0.8}}`，u 从 0 到 1；T 不写就是等温。p-V 图上走直线写 `"line":{"chamber":"A","V":末体积,"T":末温度}`。
每步由力平衡和 pV=nRT 解出活塞位置；碰卡环自动等容。取量 p_A V_A L_A T_A W_A（对外做功）dU_A Q_A x_活塞 W。
几个汽缸连通、活塞截面不同、活塞有摩擦或被拉动时用网络式：活塞写 `out`：
`"gas":{"patm":…,"chambers":[{"id":"气","p":…,"V":…,"T":…}],"pistons":[{"id":"a","A":截面积,"of":"气","out":"right","to":"另一段气体(可省,省略是大气)","m":…,"load":挂的重物重力,"F":外力(向外为正),"f":最大静摩擦,"stops":[x下限,x上限]}],"valves":[{"from":"A","to":"B","dp":…}],"steps":[{"label":"拉活塞","move":{"a":"0.1*u"},"force":{"a":"-250*g*u"},"T":{…},"adiabatic":[…]}]}`
out 是活塞向外的方向（up、down、left、right），x 是活塞向外的位移。force 是这一步加在活塞上的力（向外为正，倒铁砂这类）。valves 是差压阀：压差超过 dp 就放气。move 里的活塞按给定位移走，其余按受力平衡，受力不超过 f 就不动。取量 p_气 V_气 T_气 W_气 dU_气 Q_气，活塞 x_a、Wd_a（外界拉力做的功）、F_a、Wf_a（摩擦生热）。

# 原子物理
`"atom":{"hydrogen":5,"levels":[…],"jumps":[{"from":3,"to":1}],"all":4,"metal":{"W0":2.25}}`，能量单位 eV。hydrogen:n 用 −13.6/n² 列到第 n 级，或用 levels 从基态往上写。all:4 列出从第 4 级往下全部谱线。
单色光直接照射金属写 `"atom":{"light":{"nu":1e15,"intensity":1},"metal":{"W0":2.25},"tube":{"U":"-3+6*t/3"},"duration":3}`（或 `"lambda":500e-9`，nu、lambda、intensity、U 可含 t），取量 Eph（光子能量 eV）、Ek、Uc、nu_c（截止频率）、emit、Is（饱和光电流，正比于光强）、I（光电流）、U，节点 `达到截止频率`。
能级跃迁取量 E_2、lines（谱线条数）、dE_31、nu_31、lambda_31、Ek_31（光电子最大初动能）、Uc_31（遏止电压，V）、emit_31（能否发生光电效应，1 或 0）。
半衰期、核反应写 `"nuclear":{"species":[{"id":"Rn","N0":1000,"m0":16,"half":3.8,"to":"Po"},{"id":"Po","half":…}],"reaction":{"left":[["H",2,1],["H",3,1]],"right":[["He",4,2],["n",1,0]],"masses":{"H":…},"unit":"u"},"duration":秒}`。half 省略表示稳定，to 是衰变产物（衰变链按贝特曼公式算）。粒子写 ["符号",质量数,电荷数]：中子 ["n",1,0]，质子 ["p",1,1]，α ["He",4,2]，β⁻ ["e",0,-1]，γ ["γ",0,0]；左右两边不守恒会报错。masses 按符号给静质量（同种核写不同符号，如 D、T），u 时 1 u 对应 931.5 MeV。取量 N_Rn（剩余数）、frac_Rn（剩余比例）、m_Rn（剩余质量，需 m0）、A_Rn（活度）、lambda_Rn、n_half（已过几个半衰期）、decayed、Q（放出能量 MeV）、dm（质量亏损）、A_in/A_out/Z_in/Z_out（反应前后质量数、电荷数之和）。节点 `Rn 第2个半衰期`。

# 实验
`"experiment":{"tape":{"d":[相邻计数点间距 m],"T":时间间隔}}`，逐差法：取量 a、v_2（第 2 点瞬时速度）。

# 运动方程
别的写法都装不下时用（如带电摆、转动的杆、绳的约束、多个物体的耦合）：写状态量和变化率，引擎积分并精确找到事件时刻。
`"ode":{"state":{"th":0.5,"w":0},"rates":{"th":"w","w":"-g/L*sin(th)"},"vals":{"T":"m*g*cos(th)+m*L*w^2"},"events":[{"name":"碰到板","when":"th+0.5","dir":-1,"set":{"w":"-w"},"once":false,"stop":false}],"duration":秒,"view":[x0,y0,x1,y1],"draw":[…],"plot":{"x":"t","y":"T"}}`
- rates 写每个状态量对时间的变化率，可用 params、其他状态量、vals 里的量和 t。
- events 的 when 是一个式子，它穿过 0 的时刻就是事件（dir:1 只算由负变正，-1 只算由正变负）；set 改状态量（碰撞、换向、电性反转都这样写），stop:true 到此结束。
- draw 列画面：`{"point":[x,y],"label":"小球"}`、`{"line":[[x,y],[x,y]],"kind":"rod|rope|wall|dash"}`、`{"arrow":[[x,y],[dx,dy]],"kind":"v|F","label":"v"}`、`{"rect":[x0,y0,x1,y1],"fill":"#…"}`、`{"circle":[x,y,r]}`、`{"arc":{"center":[x,y],"radius":r,"from":0,"to":180}}`、`{"rect":[…],"B":数值}`（磁场区）、`{"rect":[…],"E":[Ex,Ey]}`（电场区）、`{"trail":[x,y]}`（走过的路径）、`{"text":[x,y],"s":"文字"}`。加 `"when":"式子"` 只在式子成立时画。坐标都可用状态量的式子。
取量 `val(状态量名)`、`val(vals 里的名字)`、`val(t)`。节点是事件的 name。
