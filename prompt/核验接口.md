# 播放器核验接入约定

此文档描述引擎输出，不要求学生 AI 填写这些结果字段。本轮没有修改 player/。

## 输入

`asks[].option` 新增 `claim?: string`，`correct` 改为可选。可计算选项必须提供 claim；旧数据只写 correct 仍能读取，来源为 AI。

```json
{"id":"A","text":"比较速率","times":{"t1":{"event":"time","t":1}},"option":{"label":"A","text":"A 的速率较大","correct":true,"claim":"v(A,t1)>v(B,t1)"}}
```

claim 与 expr 共用 at/times/vals。浮点相等推荐 `approx(a,b,1e-6,0)`，其标准为 `abs(a-b)<=atol+rtol*max(abs(a),abs(b))`；== 是精确相等。`v()` 是速率，方向使用 vx/vy/Is。时刻实参必须是 times 中的事件别名，不能写未声明的名字或裸秒数；Q/path/count 的可选对象参数有歧义时用 vals 转发。

## AskResult

| 字段 | 含义 |
|---|---|
| verified | 该问的答案/命题由内置物理独立算出，且与参考一致；两组样例须全部完成。✓ 只读此字段。它不担保未核对的讲解文字。 |
| ok | true 已核验；false 数值/命题不一致或不可用；null 未核验，包括没有参考、自定义计算、AI 声明和纯代数。 |
| answerMatch | 数值 expr 与 answer 是否一致；null 没有可比参考。true 本身不证明物理正确。 |
| source | 整问核验来源。选项优先采用命题来源，旧选项不能借附带的数值 expr 变成已核验。 |
| valueSource | 数值 expr 的来源，与选项命题分开。 |
| claimValue | 实际算得的命题真假；没有 claim 时缺省。选项“真/假”显示此值，不再直接显示输入 correct。 |
| claimOk | claimValue 与 AI correct 是否一致；没有判断式或没有 correct 时为 null。自定义方程的 claimOk=true 也不授予 verified；附带数值答案不一致时，命题匹配也不能遮盖该错误。 |
| claimSource | 判断式的来源；无判断式的选项是 ai。 |
| plotData | 已按该问场景、参数、别名和窗口算好的 [x,y,t][]，仅在有 plot 时提供。 |
| plotError | 关系图的错误信息，独立于答案核验；图表达式失败不抹掉已算出的有效答案。 |
| plotSource | 图线计算来源；图线能计算不代表选项命题已核验。 |
| plotContext | 该问的 vars、at、times、vals、window；需要重新取窗口时传给 plotPoints 的第七个参数，使用 a.sim。 |

claimValue 是第一组动画对应的结论；第二组见 `samples[1].asks`。最终 claimOk/verified 合并两组；pending=true 期间问级 ok 为 null、verified=false（已发现的不一致仍保留）。

### source

- engine：内置物理按声明模型独立计算；仍须 verified 才能画核验 ✓。
- custom：按 AI 方程、script 轨迹或用户派生公式计算；只证明积分/代入和参考的数值关系。
- ai：只有 AI 的命题结论或未经 check 的讲解。
- algebra：没有独立物理依赖的代数计算。
- unavailable / unsupported：算不出 / 超出能力。

vals 直接转发原始取量保留来源；用另一条公式命名的派生量保守归 custom，params 公式输出继承已反解物理量时也按此分级（给定模型参数的代数输入不自动变成物理证据）。由自定义方程确定的未知数保持 custom；同场景含仅由代数决定的未知输入时，下游模拟结果也保守降级，避免来源“洗白”。纯计时的 when（如 t-2）及其别名仍属 algebra；只有依赖实际物理取量的 when 时刻才继承相应来源。这些检查不证明自然语言命题与 claim/模型忠实对应。

### counts

`SampleResult.counts` 与 `verificationCounts(asks)` 给出 engine/custom/ai/algebra/uncompared/mismatch/unavailable/unsupported 八类，另外有同形的 steps 计数。

engine 只计 verified=true 的问；无可比答案的内置结果计 uncompared。没有 check 的步骤计 steps.ai，不计 steps.engine。问的数值一致和整份讲解核验完成是两回事：有未检查步骤时总标签不会是“已核验”。

## 步骤与事件画面

`StepResult` 新增 verified 和 `frame:{t,phase,snapshot}`；phase 为 before/after/at。没有 check 的步骤为 source:ai、verdict:skip、verified:false；自定义计算即使数值相符也返回 verdict:custom。

frame 是引擎实际记录的事件快照：显式 phase 优先；collide 默认 before，collided 默认 after。请让 LessonStep 保留 frame，画面直接使用 frame.snapshot，并将时间设为 frame.t。没有 frame 的自然讲解才走普通时间插值。不要再通过加减 1e-4 或总时长的某个比例模拟左右极限；同刻多事件时 snapshot 比只给一个时间更明确。

## 多变量求根边界

最多支持 3 个未知数。沿用全范围粗扫和阻尼最小二乘，并从残差盆地及远处种子启动额外搜索；最多 4 个额外起点、48 次新残差计算，结果缓存复用。坐标差按 range 宽度归一，以 1e-6 去重；找到第二个符合残差标准的根即报多解并列出候选。

这不是区间法或数学唯一性证明。有限起点、试算预算和采样精度可能漏掉极窄分支、奇异根、不连续事件附近的分支；要求清楚的物理范围和事件先后条件。不会读取 answer/correct 来选根。
