# 难题动起来

把高中物理压轴题变成可以逐问播放的动画，并且**用物理引擎独立核对答案**。

- AI 负责读题，把题目写成一份 JSON：已知量、场景、每一问要读的量、解题步骤。
- 本地引擎按这份 JSON 自己模拟一遍，在事件时刻读出每一问的数值，再和答案、每一步的 `check` 比对。对上的标“引擎核验”，对不上的直接标出来。
- 播放器按小问播放：受力分析、速度、轨迹、v-t 图像，还能先预测再看动画、改条件重算。

整个网站是纯静态的，计算都在浏览器里完成，不需要服务器，也不调用任何付费 AI 接口。

## 两种用法

### 用法一：网页 + 任何聊天 AI

适合不写代码的老师和学生。

1. 安装并打开播放器（见下面“运行”）。
2. 点“放题进来”，按网页上的三步走：放题目截图 → 复制提示词，连同截图和答案发给你的 AI（ChatGPT、DeepSeek、Kimi、豆包都行）→ 把 AI 的整段回复粘贴回来。
3. 引擎发现问题时，会生成一段“修改提示”，复制回去让 AI 改，直到能播放。

### 用法二：交给 AI 编程智能体（更准）

适合用 Claude Code、Codex、Trae、Cursor 这类工具的人。

1. 克隆本仓库，运行 `npm install`。
2. 在仓库目录里打开你的智能体，对它说：

   > 按 AGENTS.md，把这道题做成动画：（贴上题目原文、题图和答案）

3. 智能体会读 `AGENTS.md` 和格式说明，写出 `problems/<题名>/standard.json`，自己运行 `npm run check` 检查。没通过就照“修改提示”改，直到通过，最后打开播放器给你看。

**为什么更准：** 用法一里，AI 只写一次，出错要靠人把修改提示来回传话。智能体能自己运行引擎检查、自己改，一直改到所有小问都和答案对上为止，相当于把“复制修改提示 → 发回 AI → 再粘贴”这个循环自动化了。它也能直接读仓库里几十道现成例题，照着写。

## 运行

需要 [Node.js](https://nodejs.org) 22.6 或更新版本。

```bash
npm install
npm run dev
```

然后打开 http://localhost:5191 。

只想打开、不打算改代码：

```bash
npm run build
npm start
```

然后打开 http://localhost:5180 。

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发模式打开播放器（端口 5191） |
| `npm run build` / `npm start` | 打包成静态网页 `dist/`，用本地服务打开（端口 5180）。`dist/` 也可以直接上传到任何静态网站托管 |
| `npm run check -- <题目文件或文件夹>` | 检查一道题：格式校验 → 引擎模拟 → 核对答案。没通过时给出修改提示，退出码为 1 |
| `npm test` | 回归测试：题库里每道标准题都重新模拟、核对一遍 |
| `npm run prompt` | 修改 `prompt/模板.md` 后重新生成提示词 |

## 目录

```
engine/     物理引擎：表达式求值、模拟、事件、反解未知数、核对答案、格式校验
player/     播放器网页（Vite + TypeScript，二维 Canvas 和 three.js 三维）
problems/   题库：每道题一个文件夹，里面是 standard.json。播放器的“题库”直接读这里
prompt/     给 AI 的格式说明：模板.md 是源文件，提示词.txt 由 npm run prompt 生成
tools/      check.ts：给人和智能体用的单题检查命令
tests/      回归测试、浏览器验收脚本、画面自动质检（tests/质检）
AGENTS.md   给 AI 编程智能体的工作流程和红线
```

## 核验状态是什么意思

| 状态 | 含义 |
|---|---|
| 引擎核验 | 这一问的数值是引擎按场景模拟出来的，并且和答案一致 |
| 代数核对 | 只能代入公式算，没有经过模拟 |
| AI 给出，未核验 | 引擎算不了这一问，结论来自 AI，要自己判断 |
| 对不上 | 引擎算出的和答案不一样，这一问先别直接信 |

题目只给字母、没给数值时，画面里的数是为了演示任取的，界面会标“示例”，答案以式子为准。

## 能做和不能做的

引擎覆盖高中物理常见的模型：斜面、木板、圆弧和管道（含固定在可动木板上的轨道）、弹簧、绳杆、碰撞、抛体、圆周运动、电磁感应、带电粒子、电路、交变电流、振动与波、光学、热学、原子物理等。

超出能力的题会如实标出“本题超出引擎能力，未经验证”，只展示解答，不硬凑动画。

## 给开发者

- 引擎和播放器只修通用规则，不为某一道题单独打补丁。
- 改了引擎，至少跑 `npm test` 和 `npm run build`。
- 浏览器验收脚本 `tests/评审验收-*.mjs` 和画面质检 `tests/质检/质检.mjs` 需要先运行 `npm run dev`，并且本机装有 Chrome。
- 代码直接用 Node 运行 TypeScript：import 路径要写 `.ts`，不能用 enum。
